# 本地打标对比（2026-10-17，沙箱实测）

测试集：54 张网络商品/模特图，18 个品类各 3 张（牛仔裤、羽绒服、连衣裙、运动鞋、风衣、T恤、卫衣、毛衣、衬衫、半身裙、短裤、靴子、西装、斜挎包、开衫、运动裤、毛线帽、双肩包）。
原版 = z衣橱 1.2.10 自带 model_b.ort + text_embeddings.json（仅在沙箱内对比，未放入本项目）；按最近同义词归类，预处理 224、mean/std 0.5（另试 CLIP 归一化，更差）。
本项目 = SigLIP2 base（assets/models/siglip2_vision.onnx）+ 自建 9 组 367 个中英同义词向量。

| 项目 | 原版 | 本项目 |
|---|---|---|
| 品类（54） | 50 | 52 |
| 主色（54） | 7 | 52 |
| 保暖度（39） | 8 | 27 |
| 材质（27） | 24 | 23 |
| 季节（42） | 18 | 41 |

说明：
- 原版对它没有的品类放宽判对（运动裤算休闲裤、开衫算毛衣）。
- 原版颜色/保暖度/季节的向量打分接近随机，推测原 App 这几项另有规则（如像素取色），所以这三项只代表"纯向量打标"的对比。
- 样本小，结论是"品类持平略好、材质持平、其余明显更好"；真机上用自己衣服 100 张再验收。
