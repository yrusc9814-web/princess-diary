## 第 3 项：拼图旋转后拖动方向错
改 lib/pages/collage_page.dart 的 _element()（约 403 行起）。
- 原因：GestureDetector 在 Transform.rotate 里面，ScaleUpdateDetails.focalPointDelta 是旋转后局部坐标里的位移，代码直接加到屏幕坐标 e.x/e.y 上。旋转 180° 时左右上下都反了，90° 时左右变上下。
- 修法（最小改动）：在 onScaleUpdate 里先把 focalPointDelta 按 e.rot 旋转回屏幕坐标再用：
  sx = dx*cos(rot) - dy*sin(rot)；sy = dx*sin(rot) + dy*cos(rot)
  注意：rot 用本次更新前的 e.rot（双指旋转会在同一次回调里改 e.rot，先算位移再改角度）。
- 右下角缩放旋转把手（onPanUpdate 用 globalPosition 计算）和删除叉不要动。
- 若你判断"把 GestureDetector 移到 Transform.rotate 外层"更好，先在报告里说明理由，但默认按上面的最小改法。
